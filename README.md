# ATM Simulator 💳

## About

This is a beginner-friendly Python project that simulates basic ATM operations using a menu-driven program.

## Features

* PIN verification with a maximum of 3 attempts.
* Displays an ATM menu after successful login.
* Checks account balance.
* Withdraws money from the account.
* Deposits money into the account.
* Exits the program safely.

## Technologies Used

* Python
* While Loops
* If-Else Statements
* Variables
* User Input
* Basic Arithmetic Operations

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python main.py
```

## Learning Objectives

This project helps beginners practice loops, conditional statements, user input, and menu-driven programming.
